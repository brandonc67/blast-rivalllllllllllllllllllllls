# blast-rivalllllllllllllllllllllls

BLAST - a fast top-down arena shooter inspired by Roblox RIVALS. Single player vs bots or 2-player local multiplayer.

Play: open `index.html`, or via GitHub Pages once enabled.

- P1: WASD move, mouse aim/shoot, R reload, Shift/Space dash, 1-5/Q/wheel weapons
- P2: IJKL move, arrow keys aim+fire, U reload, P dash, O weapon
- Weapons: Rifle, Shotgun, Sniper, Pistol, Knife. Two maps, three bot difficulties, health packs.
